# TikTok Clean

Готовый APK: официальный TikTok + подмена страны (SIM, оператор, регион системы) + чистые ссылки +
обнулённая сторонняя аналитика. Собирается на GitHub из вашего официального APK.

Подробно: **INSTRUCTION-RU.md**. Файл сборки лежит в `BUILD-WORKFLOW.txt`
(его нужно создать на GitHub как `.github/workflows/build.yml`, потому что папка `.github`
не загружается перетаскиванием).

- `patch_tiktok.py`: переписывает вызовы Android-функций в коде TikTok на наши (`dev.clean.Hooks`).
- `hooks/`: сам «ответчик» (Java, собирается в маленький dex и добавляется в APK).
- `tests/`: тесты патчера и чистой логики.
