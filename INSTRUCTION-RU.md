# TikTok Clean: готовый APK с подменой региона и без сторонних трекеров

Итог: один файл **`TikTok-Clean.apk`** (как обычное приложение, около 100+ МБ). Ставится как любой APK, LSPatch не нужен.

Как это работает: бесплатный сервер GitHub берёт **официальный** APK TikTok, вставляет в него небольшой «ответчик» и подписывает результат. Весь TikTok остаётся настоящим.

## Что делает патч
00. **Убирает рекламные видео из ленты** (галочка `remove_ads` при запуске сборки, включена по умолчанию).
0. **Меню мода внутри TikTok** (см. «Меню мода» ниже): регион, нота, автообновление, панель администратора.
1. **Подмена страны.** Каждый раз, когда TikTok спрашивает у телефона «где SIM, какой оператор, какая страна системы», ему отвечает наш код выбранной страной. Менять SIM и ставить подмену SIM не нужно. Язык приложения и телефона не меняется, только страна.
   Страна выбирается **прямо в TikTok** в меню мода (любая страна мира, Россия подписана «старый tiktok»). В сборке выбирается только страна «по умолчанию» для первого запуска.
2. **Чистые ссылки.** «Скопировать ссылку» кладёт в буфер ссылку без меток слежки.
3. **Сторонняя аналитика обнуляется.** Адреса Google Analytics, Crashlytics, AppsFlyer, Adjust, Яндекс.Метрики и Sentry в коде заменяются на `0.0.0.0` (запрос никуда не уходит). Рекламный идентификатор Google возвращается нулевой, а не пустой, чтобы ничего не сломалось. Ничего не вырезается: классы остаются, вызовы продолжают работать.
4. При первом запуске появляется сообщение **«TikTok Clean: регион …»**. Если вы его увидели, подмена работает.

## Про рекламу (честно)
Как работает: TikTok получает от сервера список видео. Перед показом наш код выкидывает из него те, у которых признак `isAd() = да`. Адреса рекламной сети Pangle заменены на `0.0.0.0`.
- **Уберёт** обычные рекламные видео в ленте.
- **Не уберёт** рекламу внутри обычных видео (интеграции блогеров), рекламу вне ленты (поиск, LIVE и т.п.) и всё, что TikTok пометил иначе.
- Я не мог проверить это на настоящем TikTok. Названия классов взяты из того, как устроен TikTok, но в вашей версии они могут отличаться. Если так, сборка **не упадёт**, а в журнале шага Patch будет строка `WARNING: ... ads are NOT removed`. Тогда пришлите мне `report.txt` (раздел `AD FILTER`), и я подгоню патч под вашу версию.
- Если после установки лента зависает или пустая, пересоберите с выключенной галочкой `remove_ads` и напишите мне.

## Чего это НЕ делает (честно)
- **Не гарантирует, что в России всё заработает без VPN.** TikTok определяет страну не только по телефону. Он видит ещё:
  - **ваш IP-адрес** (адрес провайдера): телефон его скрыть не может;
  - **страну, записанную в аккаунт при регистрации**: она хранится на сервере.
  Подмена закрывает только то, что приложение узнаёт от самого телефона. Иногда этого хватает, чтобы лента и функции стали другими, иногда нет. Если ограничение стоит на сервере, понадобится VPN.
- Не прячет вас от серверов самого TikTok. Аналитика самой ByteDance встроена в приложение, и её нельзя убрать, не сломав TikTok.
- Название приложения остаётся «TikTok» (мы не трогаем ресурсы, иначе сборка часто ломается). Признак, что стоит наша версия, — сообщение при запуске.
- Я не мог запустить это на настоящем TikTok. Тесты проверяют патчер на макете, а код подмены компилируется. Первая сборка на реальном APK может упасть. Тогда пришлите мне текст ошибки.

## Что понадобится
- Компьютер, браузер, аккаунт GitHub (бесплатно).
- Файл **TikTok.apk**: официальный, **один файл**, не «bundle» (`.xapk`, `.apks`, `.apkm` не подходят). Для вашего Samsung нужна версия **arm64-v8a**.
  Где взять: сайт apkmirror.com → страница TikTok → выберите версию → в списке вариантов найдите строку, у которой тип **APK** (не BUNDLE), архитектура **arm64-v8a**, DPI **nodpi** → скачайте. Если у свежей версии есть только BUNDLE, возьмите предыдущую, у которой есть APK.
- 40–60 минут (в первый раз).

## Шаг 1. Репозиторий
1. На github.com: «+» → **New repository**, имя `tiktokclean`, **Public**, **Create repository**.
2. Распакуйте `TikTokClean.zip`. В репозитории нажмите **uploading an existing file**, перетащите **всё содержимое папки**, кроме скрытой папки `.github` (она не загрузится при перетаскивании, это нормально). **Commit changes**.
3. **Создайте файл сборки вручную:**
   - вкладка **Code** → **Add file → Create new file**;
   - в поле имени введите `.github/workflows/build.yml` (когда набираете `/`, GitHub сам создаёт папки);
   - откройте на компьютере файл **`BUILD-WORKFLOW.txt`** из архива в Блокноте, выделите весь текст (Ctrl+A), скопируйте и вставьте в большое поле на GitHub;
   - **Commit changes** → **Commit changes**.

## Шаг 2. Положить TikTok.apk, чтобы у GitHub была прямая ссылка
1. В репозитории справа **Releases → Create a new release** (или добавьте к адресу репозитория `/releases/new`).
2. В поле «Choose a tag» впишите `src` → **Create new tag**.
3. Перетащите `TikTok.apk` в область «Attach binaries». **Дождитесь** окончания загрузки (может быть несколько минут), затем нажмите **Publish release**.
4. На странице релиза нажмите на `TikTok.apk` **правой кнопкой → «Копировать адрес ссылки»**. Ссылка выглядит так: `https://github.com/ВАШ_НИК/tiktokclean/releases/download/src/TikTok.apk`.

## Шаг 3. Запустить сборку
1. Вкладка **Actions** → слева **Build TikTok Clean** → справа **Run workflow**.
2. Заполните:
   - `apk_url`: ссылка из шага 2;
   - `region`: страна (для начала оставьте NL; если не помогло, попробуйте DE или KZ и соберите ещё раз);
   - `change_system_region`: оставьте включённым;
   - `publish`: выключено.
3. Нажмите зелёную **Run workflow**. Ждите 15–40 минут.
4. Откройте завершённую сборку. Внизу в **Artifacts** будет **TikTok-Clean**. Скачайте, распакуйте: внутри `TikTok-Clean.apk`.
5. На странице сборки есть **Summary**: там отчёт о содержимом TikTok. Если захотите улучшить мод, пришлите мне его.
- Красный крестик: нажмите на сборку → **build** → найдите шаг с красным значком → скопируйте последние 30 строк и пришлите мне.

В окне запуска появилось поле **server_url**. Если сервер (часть «Сервер для нот и обновлений» ниже) ещё не сделан, оставьте пустым: регион будет работать, а ноты и автообновление нет. Потом можно пересобрать с адресом.

## Шаг 4. Установить на телефон
1. Перекиньте `TikTok-Clean.apk` на телефон (кабель, «Избранное» в Telegram, почта).
2. **Удалите обычный TikTok.** Подпись у нашей версии другая, поверх она не встанет. Убедитесь, что помните способ входа: вход через Google/Facebook может не сработать (из-за другой подписи), надёжнее вход по номеру телефона или почте.
3. Откройте файл, разрешите установку из этого источника. Если Play Protect ругается, нажмите «Всё равно установить».
4. Откройте TikTok. Должно появиться сообщение **«TikTok Clean: регион …»**. Войдите в аккаунт.

## Скачивание видео без водяного знака

1. В TikTok под любым видео: **Поделиться → Копировать ссылку**. Внизу экрана появится кнопка **«⬇ Скачать это видео без водяного знака»** (держится 12 секунд). Или откройте **Меню мода → Скачать видео** и вставьте ссылку.
2. Мод откроет страницу видео, найдёт все доступные файлы и покажет список: **качество, кодек и размер в МБ**. Размер без «~» точный, со знаком «~» примерный (расчёт по битрейту); точный уточняется за секунду.
3. Нажмите нужное качество. Файл сохранится в галерею, папка **Movies/TikTok Clean**, без водяного знака. Видео, у которых автор запретил скачивание, тоже скачиваются.

Честно:
- Встроенная кнопка TikTok «Сохранить видео» **по-прежнему ставит водяной знак**: я не мог найти её в коде без настоящего APK. Пользуйтесь кнопкой мода.
- Данные берутся с веб-страницы видео. TikTok может иногда показывать проверку или закрыть страницу (особенно из России без VPN), тогда мод напишет понятную ошибку. Если TikTok поменяет страницу, придётся поправить разбор: пришлите ссылку и что написано.
- **Фото-карусели**: вместо списка качеств будет кнопка «Сохранить все фото». Картинки лягут в галерею, папка **Pictures/TikTok Clean**, **звук не сохраняется**. Закрытые (приватные) посты не скачиваются.
- Размер у 1080p и выше берётся из данных TikTok. Если их нет, он примерный.

## Баннер профиля и репост комментариев
Это новые функции TikTok, их включает сервер TikTok для части аккаунтов. Включить их из мода можно, только если найти в коде их «выключатели». Без настоящего APK я их не вижу и обещать не буду. В отчёте сборки (`report.txt`, раздел `FEATURE CANDIDATES`) теперь собираются строки со словами banner / repost. Пришлите этот файл, и я сделаю включение (если выключатель найдётся и работает без сервера, иначе только интерфейс не поможет).

## Новое в этой версии

- **Нота ♪** теперь всегда у **имени** (на уровне его размера), на `@нике` только если имени рядом нет (лента, комментарии). Нажатие на ноту открывает «за что выдана» и больше **не копирует** ник: касание ноты обрабатывает мод, касание в другом месте работает как раньше.
- **Баннер в профиле** и **репост комментариев**: мод включает те «выключатели» TikTok, которые он даёт не всем аккаунтам (профильный баннер: `profile_bg_in_allow_list`, `profile_bg_enable_consumption_group`; репост: `tt_comment_repost`, `tt_comment_repost_interaction`, `tt_audio_comment_repost`, `enable_self_repost`). Я подсмотрел сам принцип в MargyT (какие настройки включать), а код написал свой: мод ищет в TikTok чтение настройки по её **названию**, поэтому он не зависит от обфусцированных имён. Переключатели в **Меню мода → Функции и лента**, после изменения перезапустите TikTok.
  Честно: это открывает кнопки в приложении. Если сервер TikTok не даёт аккаунту нужные данные, функция может не заработать. В журнале шага Patch строка `[5]` покажет, сколько мест нашлось по каждой настройке. Если везде 0, пришлите `report.txt`.
- **Фильтр рекомендаций по лайкам**: Меню мода → Функции и лента → «Рекомендации: минимум лайков» (Выкл / 100 / 500 / 1 000 / 5 000, по умолчанию 100). Работает только в ленте рекомендаций: профили, поиск, избранное, подписки и друзья не трогаются. Определяется по тому, откуда приложение читает список, и это самая неточная часть: если в какой-то ленте видео пропадают (или, наоборот, фильтр не работает), в том же меню есть строка «Последний список» с тем, что мод решил, пришлите её.
- **Liquid Glass**: нижняя панель (Главная, Друзья, Профиль…) становится стеклянной плашкой: полупрозрачная, со скруглением, бликом и тонкой светлой рамкой. Это имитация, настоящего размытия фона за панелью Android приложению не даёт. Мод находит панель по подписям кнопок, если их нет на экране, тема не применяется. **Меню мода → Оформление.**
- **Хэллоуин**: паутина в двух верхних углах, паучок на ниточке и две маленькие тыквы внизу по краям. Всё полупрозрачное, на касания не реагирует и ничего не закрывает. Включается и выключается в **Оформление**.
- **Нестабильная связь без VPN**: запросы мода (ноты, обновления, страница видео) теперь повторяются до трёх раз с паузой и ждут дольше. Сам TikTok без VPN из России зависит от провайдера и от сервера TikTok, мод на это не влияет.

## Вход через Google
Из-за того, что мод подписан нашим ключом, обычный вход через Google в приложении даёт «ошибку разработчика»: Google проверяет подпись официального TikTok. В TikTok есть второй путь входа (через браузер), которым он пользуется, когда сервисов Google на телефоне нет. Патч переключает приложение на него: нажали «Продолжить с Google» → откроется браузер → выбрали аккаунт → вернулись в TikTok.
Честно: проверить на настоящем TikTok я не мог. В журнале шага Patch строка `[6]` должна показать `1`. Если там `0`, класс в вашей версии называется иначе: входите по телефону/почте и пришлите мне `report.txt`.

## Меню мода

В любых **настройках TikTok** (Профиль → ☰ → Настройки и конфиденциальность) внизу экрана появляется розовая кнопка **«♪ Меню мода — Clean»**. Нажали: открывается меню.

- **Регион подмены.** Список всех стран мира, сверху: Россия («старый tiktok»), Германия, Нидерланды, Беларусь, Казахстан, США. Есть поиск. Выбрали, закрыли TikTok полностью (смахнуть из недавних) и открыли снова.
- **Получить ноту.** Показывает текст: «Чтобы получить ноту рядом с именем обратитесь к этому человеку в telegram: @cleanmoders» и кнопку открыть Telegram.
- **Автообновление.** Показывает, есть ли новая сборка, и ставит её поверх (данные остаются).
- **Панель администратора.** Нужен пароль (только у вас). Внутри:
  - выдать ноту: ник без @, цвет (12 цветов в палитре + ползунок любого оттенка), «за что выдана»;
  - список выданных нот с кнопкой «убрать»;
  - автообновление: номер сборки, ссылка на .apk, «что нового».

**Нота ♪** рисуется крупно после **имени** (в профиле: над `@ником`, как «Alxim🇬🇪 ♪»), у **всех** пользователей мода. Если рядом с `@ником` нет более крупного имени (например, в ленте), нота ставится после `@ника`. Нажали на ноту: написано, за что она выдана.

### Честно про меню
- Я не мог запустить настоящий TikTok. Кнопка меню появляется на экранах, у которых в названии класса есть «Setting». Если на каком-то экране её нет или она мешает, в отчёте сборки (artifact `report`, раздел `SCREEN CLASSES WITH 'Setting'`) есть список экранов. Пришлите мне его, я привяжу кнопку точно.
- Нота ищется по тексту `@ник` на экране. Если в какой-то части TikTok ник написан без `@`, там ноты не будет.
- Автообновление: приложение скачивает .apk и просит Android его установить. Если у приложения нет права «установка приложений», Android откроет ссылку в браузере, и файл нужно будет поставить вручную. Обновление встанет поверх только если подпись та же (подпись хранится в кэше GitHub, поэтому она одна и та же между вашими сборками; если кэш GitHub очистится через 7 дней без сборок, подпись станет новой, и старое придётся удалить).

## Сервер для нот и обновлений (бесплатно, один раз)

Ноты и ссылку на обновление нужно где-то хранить, чтобы их видели все. Для этого бесплатный Cloudflare (карта не нужна).

1. Зайдите на **dash.cloudflare.com**, зарегистрируйтесь (бесплатно).
2. Слева: **Workers & Pages → Create → Create Worker**. Назовите, например, `cleanmods`, нажмите **Deploy**. Потом **Edit code**, удалите весь текст, вставьте содержимое файла **`server/worker.js`** из архива, **Deploy**.
3. Хранилище: слева **Storage & Databases → KV → Create** (имя любое, например `cleanmods-kv`). Вернитесь в Worker → **Settings → Bindings → Add → KV namespace**: имя переменной строго **`BADGES`**, выберите созданное хранилище, сохраните.
4. Пароль: Worker → **Settings → Variables and Secrets → Add**: тип **Secret**, имя строго **`ADMIN_PASSWORD`**, значение ваш пароль админа. Deploy.
   **Пароль не записан ни в одном файле и не зашит в приложение**: он есть только здесь, на сервере. Приложение отправляет введённый пароль серверу, и сервер сверяет. После 8 неверных попыток с одного IP вход блокируется на 15 минут.
   Раз вы написали пароль в чате, лучше задайте другой.
5. Скопируйте адрес Worker (вида `https://cleanmods.ваш-ник.workers.dev`) и вставьте в поле **server_url** при запуске сборки. Вставлять нужно **один раз** и только адрес (без пробелов и без второго `https://`; лишнее приложение само уберёт).

Если что-то из новых функций не появилось: откройте в Actions лог шага «Patch» и пришлите мне строки `[5]`, `[5b]` и файл report.txt, там видно, что нашлось в вашей версии TikTok.

## Как выдать ноту и выпустить обновление
- Нота: в TikTok → Меню мода → Панель администратора → ник, цвет, причина → **Выдать ноту**. Через минуту-другую (приложение обновляет список каждые 10 минут и при запуске) она видна у всех.
- Обновление: соберите новую сборку (галочка `publish` включена), на странице Releases скопируйте ссылку на `TikTok-Clean.apk`. В панели админа: номер сборки = число из названия релиза (`tiktok-clean-**N**`), ссылка, «что нового», **Опубликовать**. Остальные увидят «доступна новая сборка» в меню.
  Файл .apk в сам Cloudflare не загружается (бесплатный лимит маленький, TikTok большой), поэтому используется ссылка на GitHub Releases. Для вас это ничего не меняет.

## Как проверить результат
- Сообщение при запуске есть: наш код подключён.
- Обновите ленту и проверьте, изменился ли контент, открываются ли видео, которые раньше не открывались.
- Не помогло: соберите с другой страной (шаг 3). Затем очистите данные TikTok (Настройки → Приложения → TikTok → Хранилище → Очистить данные) и войдите заново. Если ничего не меняется, мешает IP или регион аккаунта. Тогда нужен VPN.

## Если что-то не так
| Проблема | Что делать |
|---|---|
| «This is not an .apk file» в сборке | Ссылка ведёт не на APK или это bundle. Скачайте вариант **APK**, повторите шаг 2. |
| В Repack ошибка `Cannot read field "format" because "<parameter1>" is null` / `Could not smali file` | Ошибка apktool из-за слишком низкой «версии Android» для кода. Исправлена файлом `dex_api.py` (шаг уже включён в файл сборки). Обновите файлы, как в разделе «Как обновить файлы» ниже. |
| Сборка падает на Unpack, Repack или Patch по другой причине | Пришлите мне последние 30 строк. |
| Ошибка «found no SIM/region calls» | Патчер не нашёл в приложении нужных вызовов: пришлите отчёт (Summary), я подстрою. |
| Не открывается после установки | Удалите и поставьте обычный TikTok. Возможно, в этой версии есть проверка подписи. Пришлите, что видите. |
| Обновление TikTok | Повторить шаги 2–4 с новым APK. |

## Как обновить файлы, если я прислал новую версию архива
1. Распакуйте архив. На GitHub: **Add file → Upload files**, перетащите **файлы и папки из распакованной папки** (кроме `.github`): заменятся старые, добавятся новые (`dex_api.py`, `tests/test_dex_api.py`).
2. Откройте файл сборки `.github/workflows/build.yml`: карандаш → **Ctrl+A** → удалить → вставить весь текст из `BUILD-WORKFLOW.txt` → **Commit changes**.
3. Actions → **Build TikTok Clean** → **Run workflow**, как обычно.

## Важно
- Собранное приложение рассчитано на Android 8.0 и новее. На вашем Android 16 это неважно.
- Для личного использования это ваша копия приложения. Раздача такого APK другим нарушает правила TikTok и авторские права. Если будете раздавать, давайте вместе с ним ссылку на репозиторий, чтобы люди могли собрать сами и видеть, что изменено.
- Для основного аккаунта есть небольшой риск ограничений со стороны TikTok.
